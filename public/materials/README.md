# MathLang 紹介用の新規素材

2026-10-05。MathLangは、AIが数学知と実応用の条件を扱い、数学的処理を確かめて使うために開発している数理工学プラットフォームです。この素材は静的な紹介と「計算の読み方」のために新しく書きました。

3つの入口は、基本数学から工学判断へ進みます。連立方程式では、答えを元の式へ戻して確かめます。二群の評価では、データの採取条件、差の不確かさ、必要な改善幅を分けて読みます。振動では、観測と既知の条件からモデルを求め、同じ条件で有限個の候補を比べます。

## D01：2つの式から、答えと検査へ

[架空の2式](d01-start.txt)は `3x+y=5` と `x+2y=5` です。説明用に独立に代入すると、x=1、y=2で両方の左辺が5になります。残差を「左辺−右辺」と定めれば、この厳密な数の説明では両方0です。右辺を7に変えた場合はx=9/5、y=8/5となり、3×9/5+8/5=7、9/5+2×8/5=5です。

これは代入による説明例です。製品画面の実行結果、Float64の実測値、計算性能を表していません。既存の求解→残差→normと保存実行には限定された経路の検証記録があります。今回の2式手入力画面は未接続候補で、通常AI会話からの選択も未接続です。小さい残差と、真の解誤差の保証は分けて読みます。

## D02：平均差と、展開する理由を分ける

[架空の8行CSV](d02-start.csv)は、旧版4人/新版4人のスコアを示します。算術平均は旧版3.5、新版4.5です。この平均の説明だけでは、本人が採取条件を確認したことや、母集団への結論は成立しません。独立した人の比較か、同じ人の前後比較か、1人の回答数、割付などを本人が説明し、実用上必要な差と不確かさを別に確認します。

二群評価の数学層と専用会話経路には限定された通過記録があります。専用会話経路では計算、訂正、元条件の再実行を確認しています。本人発言の保存とpaired事実整合を修正中で、主ペルソナの最終受入はまだです。この新しい8行CSVの製品計算結果は掲載していません。

## D04：振動観測をモデルと候補判断へつなぐ

[新規の変位観測](d04-observations.tsv)と[宣言条件](d04-conditions.txt)は、実物測定を使わない説明用の入力です。tを秒の数値とした `x(t)=exp(-t/2)cos(t)` を0〜3秒、0.25秒間隔で作りました。生成条件は質量1kg、ばね定数1.25N/m、減衰係数1N·s/m、外力0N、初期変位1m、初期速度−0.5m/sです。この生成条件と、製品が観測から推定する結果は別のものです。

既存の固定SI、一自由度、既知質量、正のばね/減衰係数の同定と有限候補比較には、専用UIを含む限定された検証記録があります。比較の最大変位は指定した出力時刻での値です。連続時間の最大値、整定時間、一般3D、全候補の最適化を意味しません。新規ModelとこのTSVからの一巡は未受入、通常AI会話も未接続です。
