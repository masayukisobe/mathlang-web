# 架空入力から得たMathLangの数値出力

2026-10-05 / sanitized-results-v1。新しく作った架空入力を公開Processorのstdio経路で実行した保存結果から、数値だけを選び出した資料です。

| 入力 | 実出力 |
|---|---|
| `3x+y=5`、`x+2y=5` | x=1、y=2。残差[0,0]、残差l2 norm=0 |
| 1式目の右辺を7へ変更 | x=1.8、y=1.6。残差[0,0]、残差l2 norm=0 |
| 架空の変位観測13点、既知mass=1kg、自由応答 | k=1.2499999999522589N/m、c=0.9999999999731207N·s/m。観測RMSE=4.72134787384118e−12m |
| 同定値の候補とk=2.5N/m,c=1N·s/mの候補を、同じ1N外力条件で比較 | 指定出力時刻の最大絶対変位：0.9641224954880628m / 0.538757134604894m |

[D01入力](d01-inputs.json) / [D01出力](d01-results.json)、[D04入力](d04-inputs.json) / [D04出力](d04-results.json)。[D04系列CSV](d04-series.csv)は観測・同定応答・2候補の4系列、各13点です。観測と同定応答は自由応答、候補2系列は初期変位/速度0・一定外力1Nという別の条件で、それぞれ重ねて描けます。点を結ぶ線は返された時刻の表示です。

受入範囲は [acceptance.json](acceptance.json)、数理操作の版と根拠hashは [provenance.json](provenance.json)。受入対象は2変数連立と、固定SI・既知質量の一自由度同定/有限候補比較です。新入力UIや通常AI会話の受入は別欄に記しています。局所感度rank、指定時刻の最大値、有限候補の最良値という範囲で読みます。

この数値資料はWebで再計算する実行UIではありません。KBase公共知識は構想として表示します。公開版はこの新しい投影資料だけを含み、元record・trace・source・会話は内部に保持します。
